# Radix Sort

## Како работи Radix Sortot
Radix sort не ги споредува елементите меѓу себе. Тој сортира цифра по цифра, почнувајќи од единиците се движи до најголемата можна вредност:

    1. Се сортира целата низа според најмалку значајната цифра.
    2. Потоа повторно се сортира според следната цифра.
    3. Постапката се повторува додека не се обработи најзначајната цифра.

## Radix Sort со броеви

### Функции
radix_sort(vector<int>& a)
Го наоѓа максималниот елемент mx, па го повикува Count_sort по еднаш за секоја декадна цифра на mx. Променливата exp е местовна вредност (1, 10, 100, ...). Циклусот for (exp = 1; mx / exp > 0; exp *= 10) запира кога exp ќе стане поголем од mx, односно кога нема повеќе цифри за обработка.

Count_sort(vector<int>& a, int exp)
Сортирање со броење според една цифра, (x / exp) % 10:
    1. Броење: во count[10] се брои колку броеви имаат секоја цифра од 0 до 9.
    2. Збирови на префикси: count[i] += count[i-1], така што count[d] ја означува позицијата веднаш по последниот број со цифра d.
    3. Поставување: броевите се ставаат во out одејќи низ a од десно кон лево, со out[--count[d]] = a[i]. Одењето од десно кон лево го прави сортирањето стабилно.
    4. out се копира назад во a.

### Main Функцијата
Пополнува вектор со N вредности со rand(), го сортира и го печати.

### Сложеност
Нека n = број на елементи, d = број на цифри на најголемата вредност, b = основа (10).
    - Т(d · (n + b)) = Т(d · n), бидејќи b е константа.

## Radix Sort со броеви

### Функции
radix_sort(vector<string>& a)
Ја наоѓа должината на најдолгиот збор, mx. Потоа го повикува Count_sort за pos = mx-1 надолу до 0, па последната позиција на знак се сортира прва, а првиот знак последен.

Count_sort(vector<string>& a, int pos)
Сортирање со броење според знакот на индекс pos, со 257 кофи (buckets):
    - Кофа 0 е за зборови што се прекратки и немаат знак на позиција pos (pos >= size).
    - Кофи 1-256 се за вистинските вредности на знаците: (unsigned char)x[pos] + 1.
Чекорите се исти како кај броевите: броење, збирови на префикси, поставување од десно кон лево, копирање назад.

### Сложеност
Нека n = број на зборови, L = должина на најдолгиот збор, b = 257 кофи.
    - Време	Т(L · (n + b)) = Т(L · n)
